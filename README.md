# Student Dropout and Academic Success Prediction

## Project Overview
A machine learning project that predicts university students' academic outcomes using real-world educational data.

## Objectives
- Explore and preprocess the student academic dataset.
- Train a Decision Tree Classifier.
- Train a Random Forest Classifier.
- Compare both algorithms using appropriate evaluation metrics.
- Analyze model performance, limitations, and possible improvements.

## Dataset
**Name:** Predict Students' Dropout and Academic Success

**Source:** UCI Machine Learning Repository

**URL:** https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success

**DOI:** https://doi.org/10.24432/C5MC89

**Size:** 4,424 observations, 36 input features

**Target:** Dropout, Enrolled, Graduate

**License:** CC BY 4.0
